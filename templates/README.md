# 工作底稿

這些檔案不會被遊戲載入，是修改程式前先複製、填寫，再交給 AI 的底稿。
每份底稿都附有註解，說明要填什麼、程式碼每一行在做什麼。

| 底稿 | 使用時機 |
| --- | --- |
| `feature_change_plan.md` | 每個需求開始前，釐清範圍與驗收方式 |
| `new_animal.md` | 新增動物種類 |
| `new_action.md` | 新增「購買食物」「治療動物」等玩家操作 |
| `new_rule_test.py.example` | 為新規則寫一個自動測試 |

使用流程請見 [挑戰指南](../docs/challenge_guide.md#4-修改的工作流程)。
